## Исправления в тестовой копии

1. Адреса с типом после названия: «Думский пер», «Туркменский пер, д 23»; тип улицы и переулка сохраняется. Для объявления о Думском переулке распознаются 15 перечисленных улиц/переулков вместо 8.
2. Трёхдневное плановое отключение правильно разбирается как 17.08.2026 08:00 — 20.08.2026 08:00 (72 часа). Раньше обе границы определялись как 20 августа 08:00.
3. Секунды публикации не добавляются к указанному времени ремонта.
4. Продление срока обновляет одно событие и сохраняет ссылки на первоначальное сообщение и изменение. Проверена реальная цепочка: ремонт на Ленинского Комсомола, 46 → продление до 20:00 → сообщение о завершении.
5. Две перепечатки одного сообщения объединяются. Новая, более короткая редакция не отбрасывается только из-за длины текста; при неизвестной последовательности версий требуется сверка.
6. Противоречивые номера домов или типы улиц не используются для ложного автоматического подтверждения восстановления. Частичные зоны и неполные перечни остаются отмеченными как требующие уточнения.
7. Архивные августовские сообщения использованы только для проверки; в текущую ленту не возвращены.

## Реальный доступ к источникам

- MAX УРСВ `https://max.ru/id6167110467_gos`, Донэнерго `https://max.ru/id6163089292_biz`, администрация `https://max.ru/shakhtygorod`: HTTP 200, но в полученном публичном HTML доступны профили, не ленты сообщений. Нового прямого автоматического чтения MAX нет.
- `https://rovodokanal.ru/emergency-alerts/` и официальный пример `/1591`: ответ 403 на запрос проверочного сервера.
- `https://www.rovodokanal.ru/emergency-alerts/`: имя сайта не совпало с TLS-сертификатом.
- `https://shakhty.donland.ru/`: ответ 403 на запрос проверочного сервера.
- График Донэнерго: ошибка проверки цепочки TLS-сертификата. Проверка сертификатов не отключалась.
- Обе резервные RSS-ленты (`newsrostov.ru`, `news-don.ru`) читаются; получено по 200 записей и по одной перепечатке объявления УРСВ. Это вторичные неполные источники.
- RSS МЧС читается, получено 10 записей.
- Telegram водоканала читается как архив; последняя полученная публикация — 19 августа. В рабочие источники он не возвращён.

Официальный MAX API для чтения массива сообщений по `chat_id` требует, чтобы бот являлся администратором канала: https://dev.max.ru/docs-api/methods/GET/messages . Без согласованного доступа владельца канала нельзя считать прямую интеграцию настроенной.

## Что ещё не проверено

Не проведено многодневное наблюдение на телефоне, не подтверждена новая фоновая доставка Android, не получена полная прямая лента MAX/УРСВ/Донэнерго. До переноса в рабочую версию требуется интеграционная доработка отображения времени, указанного только датой, спорных редакций и неполных зон воздействия.

Исходники: `gorod-control/source-lab-v08/`. Артефакт запуска `city-sources-v08-audit` содержит `sources.json`, `evaluation.json`, `replay-tests.log`, `browser-checks.json`, снимки источников и воспроизводимые тесты. Загрузка архива не является установкой новой версии приложения.
