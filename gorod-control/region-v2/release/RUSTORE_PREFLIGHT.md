# Дон под контролем — пакет подготовки RuStore

Дата: 12.11.2026. Поддерживается новый региональный пакет `ru.citycontrol.don`; старое компактное приложение сохранено отдельно.

## Границы готовности

| Этап | Подтверждение | Статус |
|---|---|---|
| Реальный сбор MAX | Четыре профильных публичных канала, постоянное SQLite-хранилище, начальное окно 16 дней | Запущен на существующем сервере; охват области неполный |
| Сервер → приложение | HTTPS `https://chat.sportoskop.ru/don-control/`, реальные события и адреса | Работает в коротком проверенном интервале; не обещание SLA |
| Android | Сборка/lint/пакет и 7 runtime-тестов Android 15/API 35, run 43234668312 | Пройдены; телефон владельца и остальные версии Android не подтверждены |
| Постоянная подпись | Ключ/резервные копии/обновление поверх | Не подготовлены |
| Документы | Карточка, политика, условия, сведения о данных | Проекты, юридические поля не заполнены |
| RuStore | Аккаунт, карточка, медиа, модерация | Не загружено и не отправлено |
| Push | Оповещения в радиусе | Не реализованы, не обещать в карточке |

## Последовательность до отправки

1. Получить полные юридические ФИО и статус издателя, определить применимые реквизиты, контакт по данным и правообладателя. Проверить фактическую инфраструктуру и сроки хранения. Не публиковать паспорт или частные ключи.
2. Завершить вопрос использования регионального герба. Текущий preview сохраняет исходник и показывает независимый характер проекта. Окончательное оформление не менять без решения владельца.
3. Заполнить и согласовать политику/условия, разместить по постоянным HTTPS-адресам, добавить ссылки в приложение и карточку магазина. Заглушку не считать политикой.
4. Подготовить постоянный ключ и две проверенные резервные копии у владельца. Собрать релиз и проверить обновление с меньшего `versionCode` тем же ключом, сохранив точку/настройки. Временный debug APK пользователю для постоянной установки не выдавать.
5. Проверить на телефоне владельца: разрешить/отказать в GPS; «Проверить сообщения»; «Вся область»/«Весь город»/«Рядом»; три фильтра; карточка и MAX; отказ сети; удаление данных; переход в Госуслуги без автоматической отправки.
6. Снять настоящие изображения этого релиза, сверить название/описание/разрешения/возрастную маркировку с содержимым APK и текущими полями RuStore Console. Иконка 512×512, до 3 МБ, заполненный фон; состав/количество скриншотов проверить непосредственно в консоли.
7. Владелец входит в RuStore Console, проходит требуемую проверку и лично принимает соглашение. После всех проверок — загрузка подписанного APK/AAB и отправка на модерацию. Загрузка файла не равна успешной модерации или публичному выпуску.

## Правила, просмотренные 12.11.2026

Подписанный APK/AAB и уникальный пакет; для обновления сохраняются идентификатор/подпись и повышается версия. Название до 30, краткое описание до 80, полное до 4000 знаков. Карточка описывает работающие функции. При обработке персональных данных нужна русскоязычная политика в приложении и по ссылке карточки. Итоговые требования/поля повторно сверяются перед загрузкой.
