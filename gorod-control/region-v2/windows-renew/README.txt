ДОН ПОД КОНТРОЛЕМ — ОБНОВЛЕНИЕ СЕССИИ MAX
10 ноября 2026 года

Распакуй архив целиком и дважды нажми START_MAX.cmd.
Используется уже установленный Python 3.10 или новее; у Андрея ранее подтверждён Python 3.11.
Первый запуск скачает библиотеки из PyPI. Пока идёт подготовка, ничего вводить не нужно.
Затем программа предложит нажать Enter и откроет QR в браузере.
Подтверди вход через MAX на телефоне. Если нужен пароль 2FA, его символы не видны при вводе — это нормально.

Дальнейшие шаги программа покажет сама:
- Сессия создаётся в новой папке внутри %LOCALAPPDATA%\DonControlMAX. Старые файлы не удаляются.
- Проверяются только администрация Шахт, УРСВ и Донэнерго; нет вступления в каналы, отправки сообщений и отметок прочтения.
- Если отдельный канал не прочитан, программа честно покажет это. Успех входа не считается доказательством чтения всех каналов.
- По твоему подтверждению значение сессии копируется в буфер и открывается страница GitHub.
- Найди СУЩЕСТВУЮЩИЙ секрет MAX_USER_SESSION_B64, нажми карандаш, вставь значение в поле Value и нажми Update secret.
- Не нажимай New repository secret: секрет с таким именем уже есть.
- После сохранения вернись в окно и нажми Enter: программа удалит своё значение из буфера, если оно там осталось.
- Сообщи Алисе: «Секрет MAX обновил». Саму сессию и её значение в чат присылать нельзя.

Программа не отправляет секрет в GitHub автоматически. Передача происходит только при твоём Update secret.
Ничего не собирается и не устанавливается на Android. APK и работающая версия города не меняются.
Сессия технически даёт доступ к аккаунту MAX, поэтому приватную папку нельзя публиковать или пересылать.
Для отзыва сессии используй управление устройствами в MAX.

Границы проверки: исходники, локальный самотест библиотеки и подготовки новой папки проверены в Linux.
Запуск .cmd, буфер PowerShell, QR и вход на реальном Windows/телефоне ещё не проверены.
Это вспомогательный исходный запуск на Python, не собранный Windows EXE и не APK.
