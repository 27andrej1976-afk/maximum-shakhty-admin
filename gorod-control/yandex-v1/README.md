# Яндекс Карты: изолированная тестовая версия

- Боевой `gorod-control/index.html` и APK 0.9.1 не изменяются.
- Превью (после успешной публикации): https://27andrej1976-afk.github.io/maximum-shakhty-admin/gorod-control/yandex-v1/
- Для запуска Яндекс Карт нужен ключ **JavaScript API**, который пользователь вводит в поле интерфейса. В репозиторий, исходники или CI-логи API-ключ не добавляется.
- По официальной документации Яндекса требуется ограничение HTTP Referer: `27andrej1976-afk.github.io`. Активация изменений до 15 минут.
- SDK подгружается напрямую с `https://api-maps.yandex.ru/v3/` в браузере/WebView с динамическим параметром `apikey`.
- Поскольку JS API является клиентским, значение ключа будет видно в сетевых запросах браузера. Ограничение по домену обязательно; это не серверный секрет.
- Если Яндекс API недоступен, остаётся OpenStreetMap.
- Метки и сообщения берутся из существующих, уже проверяемых источников; карта не добавляет новые аварии.
- Официальная документация: https://yandex.ru/maps-api/docs/js-api/common/quickstart.html и https://yandex.ru/maps-api/docs/js-api/limit.html

Текущие ограничения: тест браузерного интерфейса использует имитацию SDK и не доказывает работоспособность пользовательского ключа или доступность тайлов на конкретном телефоне. Это нужно проверить отдельно.
