# Город под контролем — компактная версия

Поддерживается только компактное приложение. Обычная версия снята с публикации.

- [Скачать APK 1.6](water-v16/downloads/GorodPodKontrolem-Compact-Water-1.6.apk)
- [Открыть компактную страницу](compact-v11/index.html)

`app-template.txt` — общий исходный шаблон для сборки компактного приложения,
не отдельная пользовательская версия. `direct-v09`, `map-v07`, `light-v10`,
`android` и `scripts` содержат используемые им данные, библиотеки и код.
Сборка `gorod-water-apks-v16.yml` допускает только вариант compact.
История Git сохраняется; опубликованные обычные APK и их задания удалены.

Сообщения о свете сохраняются до 36 часов после объявленного окончания (без срока — от начала события). Ошибка или пустой ответ источника не подтверждает восстановление. Сохранённые сообщения помечаются как неподтверждённые; явное восстановление сопоставляется только по совпадающим адресам и домам.

MAX подключён: сервер читает до 100 последних публикаций официальных каналов администрации Шахт и Донэнерго. Адресные сообщения о воде и свете проходят проверку источника, даты и адресов; пересылки, вложения без текста и неоднозначные адреса не считаются полным подтверждением.

Версия 1.6 проверена на Android API 35: 40 проверок приложения и 69 тестов обработки данных. Ссылка на APK проверена после публикации; SHA-256: `0daa01047847094aa7bb4c4d6dd59426d0b7888d4525e6b6d06696cdcb1925d7`.

При переходе с 1.5 требуется удалить установленное приложение перед установкой 1.6: сертификаты подписи этих сборок различаются. Сохранённый домашний адрес нужно указать заново. Сессия MAX хранится на сервере и повторного подключения из-за переустановки не требует.
