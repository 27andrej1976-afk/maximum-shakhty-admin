# Город под контролем — компактная версия

Поддерживается только компактное приложение. Обычная версия снята с публикации.

- [Скачать APK 1.5](water-v16/downloads/GorodPodKontrolem-Compact-Water-1.5.apk)
- [Открыть компактную страницу](compact-v11/index.html)

`app-template.txt` — общий исходный шаблон для сборки компактного приложения,
не отдельная пользовательская версия. `direct-v09`, `map-v07`, `light-v10`,
`android` и `scripts` содержат используемые им данные, библиотеки и код.
Сборка `gorod-water-apks-v16.yml` допускает только вариант compact.
История Git сохраняется; опубликованные обычные APK и их задания удалены.

Сообщения о свете сохраняются до 36 часов после объявленного окончания (без срока — от начала события). Ошибка или пустой ответ источника не подтверждает восстановление. Сохранённые сообщения помечаются как неподтверждённые; явное восстановление сопоставляется только по совпадающим адресам и домам.
