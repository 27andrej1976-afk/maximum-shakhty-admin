## 2. Какие данные используются
Приложение позволяет без регистрации просматривать публичные сообщения о коммунальных работах. Для мониторинга выбранного дома пользователь по желанию вводит адрес либо запускает GPS. Сохранённые данные включают улицу, номер дома, координаты, текстовое обозначение точки, а при GPS — метод и возможную оценку точности определения. В WebView адрес хранится локально (localStorage); Android сохраняет ещё улицу и номер дома в SharedPreferences для фоновых проверок. Разрешение геолокации можно отклонить, остаётся ручной выбор адреса.

## 3. Цели
Адрес и координаты используются для сопоставления публичных сообщений с районом и затронутыми домами, отображения точки на карте и локального создания уведомлений. Использование GPS инициируется нажатием кнопки.

## 4. Внешние сервисы
На этапе прототипа для геокодирования используется сервис Nominatim (nominatim.openstreetmap.org): при ручном поиске ему передаётся адресная строка, при обратном поиске — координаты GPS. Карты подгружаются через OpenFreeMap / OpenStreetMap, что создаёт сетевые запросы, видимые соответствующим операторам (в том числе IP-адрес, сведения о запросе и видимая область карты). Веб-интерфейс и обновления данных загружаются с GitHub Pages. При открытии ссылок на внешние ресурсы начинают действовать правила соответствующих сайтов. Продолжительность хранения и обработка данных сторонними организациями регулируются их собственными политиками. **Этот перечень уточняется по фактическому сетевому аудиту релизной сборки.**

## 5. Обращения и фотографии
Форма «Сообщить о проблеме» готовит черновик текста и локально отображает выбранную фотографию. Приложение не подтверждает отправку или регистрацию обращения. Для официальной подачи пользователь самостоятельно переходит на Госуслуги, авторизуется и направляет сведения по правилам этого сервиса. Важно проверить итоговый APK на отсутствие скрытой загрузки фотографий перед утверждением этого раздела.

## 6. Срок хранения и удаление
Сведения о выбранном доме сохраняются на устройстве, пока пользователь не удалит их, не заменит адрес или не очистит данные приложения. В тестовой ветке предусмотрена кнопка «Удалить сохранённый адрес» с подтверждением: она удаляет локальную запись, а в Android — дополнительную копию улицы и номера дома для фонового мониторинга. Удаление локальной записи не позволяет отозвать ранее отправленные запросы у внешних сервисов.

## 7. Разрешения
Приложение запрашивает доступ к местоположению только для добровольного использования GPS; разрешение на уведомления — для локальных оповещений. Интернет нужен для карты и обновляемых сообщений. Фактический манифест APK и фоновые действия проверяются перед публикацией.

## 8. Обновления
При изменении состава данных, сервисов или способа обработки политика пересматривается. Дата и ссылка на актуальную редакцию указываются в опубликованном документе и карточке приложения.
