# MAX: подключение каналов к Городу

Подготовлен пользовательский коннектор для Windows 10/11 x64. Это не официальный SDK MAX; совместимость зависит от внутреннего протокола сервиса. Реальное чтение требует входа пользователя и не считается проверенным до получения сообщений.

1. Подпишитесь в MAX на `https://max.ru/shakhtygorod` и `https://max.ru/id6163089292_biz`.
2. Распакуйте `CityControl-MAX-Connector.zip` и запустите `CityControl-MAX.exe`.
3. Подтвердите вход по QR в приложении MAX. Если включён дополнительный пароль, вводите его только в локальном окне коннектора.
4. После успешного чтения обоих каналов коннектор предложит подготовить GitHub Secret. Вход в свой GitHub выполняйте самостоятельно в браузере. Имя Secret: `MAX_USER_SESSION_B64`; значение уже будет в буфере обмена. Не отправляйте его в переписку.
5. Нажмите Add secret, вернитесь в коннектор и нажмите Enter для очистки буфера. Сообщите: «Секрет MAX сохранён».

До проверки реальных адресов и восстановлений автоматические MAX-события остаются на проверке. Текущие источники приложения продолжают работать. Новая сборка APK для самого подключения сессии не нужна.

Сессия MAX технически имеет права всего аккаунта. Коннектор запрашивает историю только двух разрешённых публичных каналов, ничего не отправляет, не вступает в каналы и не ставит отметки прочтения. Начальная синхронизация SDK может получить метаданные аккаунта. Для постоянной работы рекомендуется отдельный аккаунт. Сессия хранится в профиле Windows `%LOCALAPPDATA%/CityControlMAX`; при облачном подключении — также в GitHub Actions Secret. Доступ к ней имеют задания репозитория, поэтому нельзя запускать с ней недоверенный код.

Сбор без постоянно включённого ПК использует существующее серверное расписание приложения. Расписание GitHub может задерживаться. Проверяется до 100 последних публикаций каждого канала; вложения и пересылки пока пропускаются. Это не гарантия полной ленты.

Отключение: завершите сессию в MAX → устройства и удалите `MAX_USER_SESSION_B64` в GitHub. Удаление одного локального файла не отзывает серверную сессию.

Основание: https://dev.max.ru/docs-api/methods/GET/messages (боту нужны права администратора); https://docs.pymax.org/api/client-web.html (QR-сессия); https://docs.pymax.org/messages.html (чтение истории).
